# Natural disaster and COVID-19 experiences and depression

Repository for scripts used in statistical analyses to explore the association between exposure to natural disaster and traumatic experiences related to bushfires/flooding and/or COVID-19 with the number of depression symptoms, adjusting for polygenic risk of depression
